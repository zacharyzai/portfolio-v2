# Zachary Zai — Personal Portfolio

My personal portfolio site, built to showcase projects, skills, and experience.

## Tech Stack

- **Framework** — Next.js 16 (App Router)
- **Language** — TypeScript
- **Styling** — Tailwind CSS
- **Animations** — Framer Motion
- **3D Background** — Three.js (animated dot-wave canvas)
- **Icons** — Lucide React, React Icons (Simple Icons)
- **Theme** — next-themes (forced dark mode)

## Sections

- **Hero** — Animated name reveal, role, and social links
- **About** — Bio and personal highlights
- **Projects** — FinFlow, Campus Event Board, and more
- **Experience** — Timeline of education, work, and activities
- **Skills** — Tech stack organised by category with a scrolling logo ticker
- **Contact** — Social links and contact form

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Deployed on Vercel. Push to `main` to trigger a new deployment.
